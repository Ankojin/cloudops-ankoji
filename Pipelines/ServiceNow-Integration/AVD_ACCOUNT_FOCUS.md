## 🔄 **Pipeline Flow for AVD Accounts**

1. **ServiceNow Request** → User submits AVD account request
2. **Parse Request** → Extract user details and AVD configuration
3. **Validate Request** → Business rules for AVD requirements
4. **Generate UPN** → Create UPN: `ahmmoh-E@babgroup.com`
5. **Execute Creation** → 
   - Create Azure AD user
   - Configure AVD host pool access
   - Assign application groups
   - Set workspace permissions
6. **Update Status** → Return results to ServiceNow

## 🎯 **AVD-Specific Business Rules**

### Validation Rules:
- **Host Pool Assignment**: Required for AVD accounts
- **Application Groups**: Minimum one application group required
- **Department Validation**: Finance users → Finance apps, IT users → IT apps
- **Session Timeout**: Default 480 minutes (8 hours)

### Security Requirements:
- **MFA Required**: Always enabled for AVD accounts
- **Device Compliance**: Required for external access
- **Location Restrictions**: Based on company policy
- **Conditional Access**: Enhanced security for remote access
